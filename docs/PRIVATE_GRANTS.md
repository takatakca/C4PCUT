# Private operator-managed product grants (reference only)
An offline operator CLI and read-only Node lookup adapter provide a durable local pilot registry for C4PCUT access. They are not a subscription processor or TAKATAK's authoritative billing database. No real customer is provisioned by this release.

Use a dedicated owner-only directory outside source control on a trusted Linux host. Never put customer UUIDs or registry records in GitHub. The operator, after independently verifying an approved access grant, may run integration/manage-grants.py with --registry /absolute/private/path/grants.json --client CLIENT_UUID grant --plan free|standard|pro --until UTC_EPOCH_SECONDS. For revocation use revoke without plan or expiry. Each write has a lock, atomic replacement, private permissions and bounded before/after audit history. No implicit access and no checkout. Maximum 500 clients, 1000 changes, 256 KiB, and validity up to 366 days; hitting caps fails closed rather than silently deleting audit records. Preserve and back up the file and lock directory. Audit is operator-local, not tamper-proof, and identity is not verified by the CLI itself. Do not expose the CLI over HTTP.

The server-only lookupPrivateGrant(path,clientId) adapter rereads the registry per request. Use as injected lookupEntitlement only in an explicitly approved private pilot with the real TAKATAK workspace guard and fixed server-owned path. It denies absent, invalid, revoked or expired grants. Previously issued assertions remain valid until their short expiry; already queued renders are not revoked. A proper TAKATAK authoritative database grant and billing reconciliation remain required for commercial launch.
